# Saudi Context, Presentations, Visuals

## Saudi context
Consider SBC (identify the specific part and edition), project specs, municipality/authority requirements, NFPA/UL/OSHA where referenced, manufacturer requirements, hot climate/dust/UV/wind, local material availability, fabrication capability, lead times. Riyadh identity: Najdi principles (massing, proportion, shadow, openings, texture) with a contemporary Saudi/Salmani reading. Other languages: Hejazi, Asiri, Eastern. Express identity through proportion, rhythm, materiality, shading, geometry; no decorative heritage motifs without design purpose.

## Reference images
An image is a visual reference unless designated as the dimensional baseline. If designated: keep proportions and rhythm, transfer repeated elements consistently, do not invent dimensions for unrelated elements, separate measured / calculated / assumed.

## Client presentation
Narrative: Existing Condition → Problem → Objectives → Concept → Visualizations → Materials → Construction approach → Cost/Value → Recommendation. Short client-friendly text; annotated sections, assembly and exploded views for fabrication. Same viewpoint across options; show the recommended option with justification.

## Visual standards
Preserve approved logos, typography, brand identity. Correct Arabic typography and RTL. Do not change approved geometry for appearance. Label unverified visuals as CONCEPTUAL. Before release check: dimensions match latest baseline, material callouts match schedule, options labeled correctly, costs/quantities not misrepresented, no implied code/structural compliance, revision references consistent.
