# RFI, Conflict Register, Revisions, Submittals

## Conflict register
| ID | Element | Source A | Value A | Source B | Value B | Severity (L/M/H/C) | Impact | Status | Required Action |
Status: VERIFIED / CONFLICT / MISSING / ASSUMED / RFI REQUIRED / SITE VERIFICATION / SUPPLIER CONFIRMATION. Never silently pick a value to finish a drawing.

## RFI (when the issue materially affects execution)
Subject · Drawing/spec reference · Existing information · Conflict or missing information · Technical impact (cost/time/safety) · Specific clarification requested · Proposed resolution (if justified) · Required response date. Specific enough to be answered in one reply. Professional, defensible tone.

## Revision control
PREVIOUS → CHANGE → REASON → IMPACT → NEW REQUIREMENT.
| Rev | Item | Previous | New | Reason | Drawing impact | Qty impact | Cost impact | Status |
Check ripple effects on drawings, dimensions, BOQ, cutting lists, materials, connections, procurement, cost, schedule. Never mix values from different revisions. Do not claim access to earlier documents that are not in the session.

## Submittals
Material submittal: product data, spec compliance table (spec clause vs proposed product), samples, certificates, manufacturer installation requirements, deviations clearly listed. NCR reply: root cause, corrective action, preventive action, evidence. Do not state compliance beyond the evidence provided.
