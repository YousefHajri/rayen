# Coordination & BIM

Inspect common conflict zones: false ceilings, HVAC, lighting, fire fighting, fire alarm, containment, plumbing, access panels, doors, joinery, signage, beams, columns, shafts, supports.

Clash types: hard, soft/clearance, access, maintenance, installation, sequencing/workflow.
Register: | No. | Location | Discipline A | Discipline B | Clash | Impact | Resolution | Priority | Responsibility |
Priority: Life safety → Structure → Major MEP → Function → Constructability → Aesthetics; rank by risk × impact × likelihood.

BIM/Navisworks: model accuracy, clash tests, quantity extraction, 3D interfaces, installation sequence, 4D logic. Use actual model data only when accessible. Never claim "clash-free" without a coordinated model review.

For full BIM workflow (ISO 19650, LOD, clash matrix, IFC audit script) load `rayen-bim`.
