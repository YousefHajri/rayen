# Newtech context

Newtech (نيوتك للدعاية والإعلان) — Riyadh-based manufacturer and installer of advertising signage, LED screens/displays and interior fit-out (graphics, acrylic, frames, wayfinding).

## Typical product families
| Family | Typical build-up | Key checks |
|---|---|---|
| Channel letters (3D letters) | Aluminum/SS returns 0.8–1.2 mm, acrylic face 3–5 mm, LED modules, back tray | Face-to-return fixing, drainage holes, LED spacing vs letter depth, PSU access |
| Lightbox / fascia | Aluminum or GI frame, ACP cladding 4 mm, acrylic/flex face, LED | Frame to substrate anchors, service access panel, IP rating of electrics |
| Pylon / totem | Steel RHS/CHS core frame, ACP or aluminum skin, base plate + anchor bolts | Wind load per SBC 301, foundation by structural engineer, earthing |
| Wayfinding & room ID | Acrylic, aluminum composite, vinyl graphics, magnetic or stud fixing | Mounting height, ADA/accessibility text heights if specified, fixing to substrate |
| Interior graphics frames | Aluminum/wood frames (e.g., 30×30 mm), acrylic 3–5 mm, magnetic fixing | Concealed fixings, existing substrate condition, replaceability |
| LED screens | Cabinet modules (e.g., 500×500 / 960×960 mm), steel support frame | Pixel pitch vs viewing distance, cabinet weight, ventilation, rear/front service |

## Standard sheet & stock sizes (ASSUMED until supplier confirms)
- Acrylic: 1220×2440 mm and 2050×3050 mm; thicknesses 2, 3, 5, 8, 10 mm.
