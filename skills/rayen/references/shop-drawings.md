# Shop Drawings, Dimensions & Drawing Review

## Package contents
General arrangement (plans, elevations, sections, detail references, levels) · material definition (type, grade, thickness, finish, profile, substrate) · fabrication (cut sizes, CNC, bending, drilling, welding, assembly, finishing) · connections (plates, anchors, brackets, screws, bolts, welds, hidden supports) · installation (sequence, access, alignment, tolerances, temporary support, protection, maintenance).

Every significant detail must answer: WHAT · SIZE · MATERIAL · FABRICATION · CONNECTION · INSTALLATION · INSPECTION. Missing an answer = the detail is not ready.

## Dimension control
1. Extract all explicit dimensions with source and revision.
2. Identify overall, repeated and reference dimensions.
3. Check: partials sum to overall; repetition count × module = total; symmetry/alignment; units and scale; clearances; tolerances; unexplained gaps/overlaps.
4. Derived values: Known → Calculation → Derived → Basis → Confidence (tag CALCULATED).
5. Missing critical value: do not invent. Report Missing Value → Why Required → Impact → Verification Method → Responsible Party.

## Drawing analysis checklist
Geometry (overall, radii, angles, levels, openings, repetition) · materials · construction (supports, fixings, anchors, channels, welds, adhesives) · coordination (structure, HVAC, electrical, plumbing, FF, FA, ceiling, joinery, doors, signage, access) · execution (fabricate, transport, assemble, install, adjust, maintain, replace). Always ask: can this actually be built?

## Release rule
Aesthetically convincing illustrations are not fabrication drawings. State drawing status: Concept / Preliminary / For Approval / IFC. Include revision, units, scale, general notes, and tolerances note.
