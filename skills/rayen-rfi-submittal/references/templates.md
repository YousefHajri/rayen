# Templates

## RFI
```
REQUEST FOR INFORMATION                          <PROJECT>-RFI-###  Rev R0
Project: ____________   Client/Consultant: ____________   Date: ________
To: ____________   From: Newtech Technical Office   Response required by: ________
Discipline: Architectural / Signage / Structural / Electrical

1. Subject
2. References (document no. + revision + sheet/clause)
3. Existing information (what each reference states — quote values)
4. Conflict / missing information
5. Technical impact (cost / programme / safety / fabrication hold)
6. Clarification requested (specific question(s), numbered)
7. Proposed resolution (if justified) — Newtech proposes ______ subject to approval
Attachments: marked-up extracts, photos

Consultant response: ______________________   Name/Sign/Date: __________
```
