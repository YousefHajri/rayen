# PMO governance for Newtech

PMO type: controlling (standard templates, mandatory reporting, gate reviews). Decisions stay with management; the PMO reports, checks and escalates.

## Stage gates

| Gate | Stage | Exit criteria (evidence) |
|---|---|---|
| G0 | Lead / tender | Go/no-go, tender BOQ priced (rayen-boq-qto), margin approved |
| G1 | Award | LOA/PO received, charter approved, PM assigned |
| G2 | Design & Shop Drawing | Shop drawings submitted and approved (code A/B), structural calc issued where needed |
| G3 | Procurement | Material submittals approved, POs issued, lead times confirmed |
| G4 | Fabrication | Factory QC/ITP passed, sample approved |
| G5 | Installation | Permit, site access, method statement + HSE approved; installation complete |
| G6 | Handover | Testing & commissioning, snag list closed, acceptance certificate |
| G7 | Close-out | Final account, as-builts, warranty, lessons learned |

A gate is passed only with evidence; missing evidence is listed as TO BE CONFIRMED with an owner.

## RAG (single rule set for every report)

- **GREEN**: CPI ≥ 0.95 and SPI ≥ 0.95, forecast end ≤ contract date, no open HIGH risk without a response.
- **AMBER**: CPI or SPI 0.90–0.95, or forecast slip ≤ 5 working days, or waiting on an external input.
- **RED**: CPI or SPI < 0.90, forecast end beyond the contract date by > 5 working days, a critical-path task blocked by an overdue approval, or an open safety/structural issue.

## Portfolio KPIs

Projects by RAG · total BAC / EV / AC / EAC · portfolio CPI & SPI · projects late vs contract · open HIGH risks · changes pending approval (count + value) · overdue RFIs/submittals (from rayen-reports).

## Cadence

Weekly: project update (progress %, cost, risks, issues) → PMO dashboard (Sunday morning, Riyadh). Monthly: portfolio review with management, baseline and resource check. At each gate: gate review record.

## Change control authority (default; replace with company policy)

| Change value / impact | Approver |
|---|---|
| No cost, ≤ 2 days, off critical path | PM |
| ≤ 5% of BAC or ≤ 5 days | Projects manager / sponsor |
| > 5% of BAC, contract date moves, or scope change requested by client | Management + client variation order |
