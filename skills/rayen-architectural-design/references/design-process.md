# Design process, deliverables, critique

## Stages & deliverables (RIBA / AIA-style, adapt to contract)
| Stage | Purpose | Key deliverables | Gate question |
|---|---|---|---|
| 0 Brief | Define need | Brief, program (XLSX), budget class, site data list | Do we know what success is? |
| 1 Concept | Big idea | 2–3 options, zoning, massing, precedent board, cost class | Which direction and why? |
| 2 Schematic (SD) | Fix layout | Plans/sections/elevations 1:200–1:100, area schedule, outline spec, code strategy | Does it pass code + budget? |
| 3 Design Development (DD) | Fix systems | 1:100–1:50, façade system, finishes concept, coordinated MEP zones, BIM LOD 300 | Is it coordinated? |
| 4 Construction Docs / IFC | Build | 1:50–1:5 details, specs, schedules, BOQ | Can a contractor price and build it? |
| 5 Shop drawings / fabrication | Make | Shop drawings, cutting lists, CNC files, method statements | Can the factory make it right first time? |

## Design thinking checklist
Context (climate, urban edge, views, noise) · Users & journeys (arrival, wayfinding, waiting, work, service, VIP, female/family zones where required) · Program fit (net/gross, growth) · Organisation (axis, grid, core, layers public→private) · Light (daylight, glare, night identity) · Material & tectonics (what is it made of, how is it joined, how does it age in Riyadh sun/dust) · Structure (grid, spans, transfer) · Services (shafts, ceiling void, plant, access) · Sustainability (orientation, shading, WWR, insulation, water, Mostadam if targeted) · Cost & buildability · Identity.

## Review checklist (drawings received or own design)
1. **Life safety**: exits count & separation, travel distance, dead ends, exit width vs occupant load, stair/ramp geometry, guard/handrail, fire compartments & shafts, smoke, Civil Defense access.
2. **Accessibility**: accessible route from parking/drop-off, entrance, door clear widths & maneuvering, accessible WC per floor/sex, lift, counters, signage.
3. **Code / authority**: setbacks, height, coverage/FAR, parking, use classification, Balady requirements, special zone design codes.
4. **Structure interface**: grid continuity, column clashes with rooms/doors, slab openings, cantilevers, roof loads (signage, plant).
5. **MEP interface**: shafts stacked, ceiling void depth vs ducts, wet areas over wet areas, plant rooms & access, DB/IT rooms.
6. **Function**: adjacencies, furniture fit, storage, back-of-house, waste, delivery.
7. **Envelope**: orientation, shading, water-proofing, drainage, expansion joints, thermal bridges.
8. **Documentation**: dims close, levels, grids, references, door/window/finish schedules, revision clouds.
